# ANTIBODY (অ্যান্টিবডি)

A browser game teaching a naive alien to survive Dhaka's mobile-money and phone scams.

## Quick Start
```bash
# Install dependencies
pnpm install

# Start both API and Web client concurrently
pnpm dev
```

- API Server: `http://localhost:4000/api/v1`
- Web Client: `http://localhost:3000`

## Run Tests
```bash
# Run unit & classifier tests
pnpm test
```

## Docker Deployment
```bash
docker compose up --build
```
